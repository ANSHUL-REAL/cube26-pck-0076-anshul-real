File format

One row per order. order_id and order_lines are required.

order_id,order_lines,channel,unit_id,shipment_id
ORD-1001,CAP-BLUE:1;MUG-SET2:1,shopify,BOX-1001,SHP-5501
ORD-1002,CAP-RED:2,amazon_mfn,BOX-1002,

order_lines is SKU:quantity, separated by semicolons. A quantity counts sellable units: a boxed set of 2 mugs is 1.

Optional: channel, unit_id, client_id, and shipment_id when the box already has an outbound shipment. Recovery matches charges to records by shipment.

Orders are always added to {{ user.org_name }}. Any company column in the file is ignored.
